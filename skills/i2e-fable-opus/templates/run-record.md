# Run record

Keep this record as short as the task allows; omit inapplicable fields. Keep it, its
evidence, and the failure ledger in a private task directory outside the owned
source scope. Put at most a sanitized summary in an issue or handoff location, and
only within the user's disclosure authority. Do not store secrets. Record what
actually happened; never fill a field from this template or from expectations.

- Outcome, mode, and profile (CHANGE or READ_ONLY; full profile or proportionate):
- Source of truth / repository / base revision:
- Applicable instructions and known worktree changes:
- Scope, exclusions, invariants, assumptions:
- Existing authority and any action-specific missing decision:
- Acceptance criteria and the required checks that prove each:
- Verification assets (verify skill, feature map, REVIEW.md, checklist, check commands):
- Library entries used (properties, rules):
- Subagents: role, agent type, agent ID, model, effort:
- Failure consultations and captures:
- Plan file, decision IDs, material replans:
- Doubt reviews proposed, the user's answer to each, findings, and resolution:
- Work items and checks: RED and GREEN (test ID, command, result), required and regression checks, candidate:
- Blind-spot checks (leave and come back, every path to each message, documents against each other, break it on purpose): evidence, or why each does not apply:
- End-to-end, property, and differential evidence (file paths); proof gaps:
- Security audit: trigger, outcome, findings:
- Main code review: rounds, verdicts, findings:
- Library entries added or updated; rules proposed:
- Authorized external actions and readback:
- Usage source, input/cached/output, elapsed time, missing accounting:
- Completion state and next action if incomplete:

Record the successful fetch receipt, its commit and selected IDs for each new or resumed invocation. At successful handoff, record the reflection result, the published IDs and merged revision, or the reason publication is pending. Keep the completion receipt and raw observations private.

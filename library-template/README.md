# Local property and rule drafts

This template supports the existing offline draft workflow. Use its templates and the local checker to prepare individual public-safe entries. Keep the original checkout and any private history local. All three I2E workflows fetch the [canonical catalog](https://github.com/bowang-solutionstream/i2e-team/tree/main) and publish reviewed drafts there at successful handoff.

Start from the [property template](templates/property.md) or [rule template](templates/rule.md). An entry records a scoped observation. Adoption and enforcement have separate requirements in the canonical guide.
